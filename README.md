# cocoaModem — Swift port

[cocoaModem](https://www.w7ay.net/site/Applications/cocoaModem/) (Kok Chen,
W7AY) is an amateur-radio digital-mode modem app for macOS, originally
written 2004–2011 in manual-retain-release Objective-C (~88k lines, ~270
source files, 19 modem modes: RTTY, Wideband RTTY, Dual RTTY, PSK, MFSK,
Hellschreiber, Wideband CW, SITOR-B, HF-FAX, Synch-AM, and more). This repo
is a full port of that application — "cocoaModem - Swift - 1.0" — to Swift
and modern macOS, published with the kind permission of Kok Chen's widow.

## Download

**[Download cocoaModem - Swift - 1.0 →](https://github.com/mark-oskin/cocoaModem-Swift/releases/latest)**

Signed with a Developer ID certificate and notarized by Apple — download the
`.dmg`, drag the app into Applications, and launch it. No build tools needed.

## Status

The app has been fully converted from Objective-C to Swift and builds/runs
on modern macOS (14+). Every mode tab loads and launches without crashing.

**Caveat:** DSP demodulation and contest-logging *correctness* cannot be
validated without a radio + audio input; build/launch tests only prove the
code paths don't crash. On-air / recorded-signal A/B testing against the
original Objective-C build is still open (see Follow-ups below).

## Repo layout

```
Sources/            All application code — 278 .swift + 45 .h, mirroring
                     the original class layout (Modems/, Interfaces/,
                     Instrumentation/, Audio/, PTT/, Contest/, …).
App/                 Everything needed to assemble the app bundle:
                       Info.plist, cocoaModem-Bridging-Header.h,
                       cocoaModem.pch, cocoaModem-Swift.sdef (AppleScript
                       dictionary), icon/, AppleScripts/, and Resources/
                       (contest XML templates, Hellschreiber .font files,
                       Japanese charset tables, English.lproj +
                       Japanese.lproj localized nibs/strings).
docs/                Historical design notes and reference material carried
                     over from the original project (audio class hierarchy,
                     changelog, CW keying-envelope notes); docs/historical/
                     holds dead-code references kept for context only.
tools/               hierarchy.py / pbx_swift.py — one-off scripts used
                     during the Obj-C→Swift conversion (see below). Not
                     part of the build.
project.yml          xcodegen spec — the single source of truth for the
                     Xcode project (see Build below).
CreateFont/           Historical standalone utility (Hellschreiber font
AppleScript Tests/    generator) and AppleScript regression tests —
                     unrelated to the main app build, kept for reference.
```

`cocoaModem-Swift.xcodeproj` is generated by xcodegen and gitignored — never
edit it directly; edit `project.yml` and regenerate.

## Build

```sh
xcodegen generate
xcodebuild -project cocoaModem-Swift.xcodeproj \
           -scheme "cocoaModem - Swift - 1.0" -configuration Release build
```

Requires xcodegen (`brew install xcodegen`). `CreateFont` and
`AppleScript Tests` are separate, self-contained Xcode projects (historical
tooling) and are not part of this build.

Curious how the Objective-C → Swift port was actually done (nib/KVC
compatibility, the DSP class-hierarchy conversion order, gotchas hit along
the way)? See [docs/CONVERSION-NOTES.md](docs/CONVERSION-NOTES.md).
